### GitSource

Git source configuration for fetching code. Ravion partially clones the full history of `branch`
plus tags, fetching file contents on demand, then checks out `ref` if set. Other branches are not
fetched. Set `fetch_depth` for a shallow clone.

<ResponseField name="type" type="enum" required>

</ResponseField>

<ResponseField name="repo" type="string" required>

  _(minLen:1; templateable)_
</ResponseField>

<ResponseField name="ref" type="string | null">
  Git ref to check out — branch, commit SHA, tag, or other ref. Overrides branch HEAD if set.

  _(templateable)_
</ResponseField>

<ResponseField name="fetch_depth" type="integer | null">

  _(format:int32,min:1; templateable)_
</ResponseField>
