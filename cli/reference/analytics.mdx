## `ravion analytics`

Read analytics

### `ravion analytics ci`

Read CI job analytics: totals, daily trends, rankings, single jobs, test timings, and runner right-sizing

**Aliases:** `cis`

#### `ravion analytics ci cost-breakdown`

CI costs by repository, pipeline or job

```bash
ravion analytics ci cost-breakdown [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--from <string>` | yes | First day of the range (UTC), inclusive. |
| `--group-by <string>` | yes | How /ci/analytics/costs/breakdown groups costs. Available values: repository, pipeline, job. |
| `--to <string>` | yes | Last day of the range (UTC), inclusive. Must be on or after from; the range covers at most 400 days. |
| `--code-source-id <string>` |  | Only GitHub Actions jobs of this code source (repository). Returns 403 when the caller cannot read it. |
| `--conclusion <string>` |  | Only jobs that ended this way. Available values: success, failure, cancelled, timed_out, skipped. |
| `--execution-environment-id <string>` |  | Only jobs that ran in this execution environment. |
| `--json` |  | emit response as JSON |
| `--limit <int>` |  | How many items to return, 1 to 100. Defaults to 25. |
| `--name <string>` |  | With scopeId, only the workflow job or pipeline step of this name, as Workload.name gives it. |
| `--pipeline-id <string>` |  | Only steps of this pipeline. Returns 403 when the caller cannot read it. |
| `--runner-size <string>` |  | Only jobs booked at this runner size, as Job.runnerSize labels it (for example "8 vCPU / 32 GiB"). |
| `--scope-id <string>` |  | With name (and source), only one workflow job or pipeline step: the code source ID for GitHub Actions jobs, the pipeline ID for pipeline steps. |
| `--source <string>` |  | Only jobs from this source. Available values: github_actions, pipeline. |
| `-v, --verbose` |  | show full output |
