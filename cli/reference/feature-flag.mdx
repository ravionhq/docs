## `ravion feature-flag`

Inspect the features on for the organization

**Aliases:** `feature-flags`

### `ravion feature-flag list`

List the features on for the organization

```bash
ravion feature-flag list [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--environment-id <string>` |  | Narrow the list to an environment in the organization. |
| `--json` |  | emit response as JSON |
| `--module-instance-id <string>` |  | Narrow the list to a module instance in the organization. |
| `--pipeline-id <string>` |  | Narrow the list to a pipeline in the organization. |
| `--project-id <string>` |  | Narrow the list to a project in the organization. |
| `-v, --verbose` |  | show full output |
