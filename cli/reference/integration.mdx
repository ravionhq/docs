### `ravion integration slack`

Manage Slack integrations

#### `ravion integration slack connect`

connect opens Slack's authorization page for your organization in a browser and waits for you to allow the install. Once Slack redirects back, the workspace appears as a Slack integration and its id is printed. Re-running for an already-connected workspace updates that integration in place.

```bash
ravion integration slack connect [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--json` |  | emit response as JSON |
| `--no-browser` |  | Print the consent URL instead of opening a browser |
| `--timeout <duration>` |  | how long to wait for the install to complete |
