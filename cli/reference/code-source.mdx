### `ravion code-source create`

Create CodeSource

Flags depend on --type:
  GITHUB: requires --github-installation-id, --repo-url
  GITLAB: requires --gitlab-third-party-account-id, --repo-url
  GITLAB_SELF_HOSTED: requires --git-self-hosted-server-id, --gitlab-third-party-account-id, --repo-url

```bash
ravion code-source create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--repo-url <string>` | yes | Git repository URL |
| `--type <string>` | yes | type. Available values: GITHUB, GITLAB, GITLAB_SELF_HOSTED. |
| `--git-self-hosted-server-id <string>` |  | Git self-hosted server ID |
| `--github-installation-id <string>` |  | GitHub installation ID |
| `--gitlab-third-party-account-id <string>` |  | GitLab third-party account ID for OAuth |
| `--json` |  | emit response as JSON |
