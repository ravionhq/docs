## `ravion github-actions`

Browse GitHub Actions workflows, runs, jobs, and logs

### `ravion github-actions job-logs`

Get bounded logs for a workflow job

```bash
ravion github-actions job-logs <codeSourceId> <jobId> [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--json` |  | emit response as JSON |
| `--organization-id <string>` |  | organizationId |
