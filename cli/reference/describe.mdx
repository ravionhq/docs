## `ravion describe`

Resolve /go/&lt;service-account-id&gt; and other supported UI-backed resource IDs to safe resource details and dashboard links.

Supported IDs include organizations, projects, environments, pipelines and runs, modules, deployments, stacks, service accounts, API keys, memberships, AWS accounts, execution environments, module categories, default-value definitions, deployment resources, and code sources. IDs without a UI destination, such as standalone users and provider workflow, run, or job IDs, are not supported.

```bash
ravion describe <id> [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--json` |  | emit response as JSON |
