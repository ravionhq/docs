## `ravion values`

List possible values for things like aws regions

**Aliases:** `value`

### `ravion values aws-ecr-image`

Get AWS ECR image values

```bash
ravion values aws-ecr-image [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--image-ref <<account>.dkr.ecr.<region>.amazonaws.com/<repository>:<tag>>` | yes | Fully-qualified ECR image references (&lt;account&gt;.dkr.ecr.&lt;region&gt;.amazonaws.com/&lt;repository&gt;:&lt;tag&gt; or `…@sha256:&lt;digest&gt;`). Non-ECR references are rejected. |
| `--json` |  | emit response as JSON |
| `-v, --verbose` |  | show full output |
