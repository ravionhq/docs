```bash

```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |

| `--country <string>` | yes | Two-letter ISO country code. |
| `--line1 <string>` | yes | line1 |
| `--name <string>` | yes | Name invoices are addressed to, usually the company. |
| `--postal-code <string>` | yes | postalCode |
| `--json` |  | emit response as JSON |
| `--line2 <string>` |  | line2 |
| `--tax-id <string>` |  | The tax registration number to charge invoices under, e.g. a VAT number or EIN; its Stripe type follows the address country. Omit to remove the registration on file. |
