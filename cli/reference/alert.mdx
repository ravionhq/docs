## `ravion alert`

Manage alerts

**Aliases:** `alerts`

### `ravion alert create`

Create an alert

```bash
ravion alert create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--data <string>` | yes | Request data as JSON |
| `--json` |  | emit response as JSON |

### `ravion alert end`

End an alert

```bash
ravion alert end <alertId> [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--json` |  | emit response as JSON |


**Flags:**
