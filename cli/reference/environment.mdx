## `ravion environment`

Manage environments

**Aliases:** `environments`, `env`

### `ravion environment create`

Create Environment

```bash
ravion environment create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--given-id <string>` | yes | User-provided environment identifier. Must be unique within project. |
| `--name <string>` | yes | name |
| `--project-id <string>` | yes | projectId |
| `--description <string>` |  | description |
| `--json` |  | emit response as JSON |

Patch Environment


| --- | --- | --- |
| `--canvas <string>` |  | The saved module canvas: where each card sits, how cards are grouped, and which metrics they chart. Presentation only — it never affects deployments. Patching replaces the whole canvas; an environment that has never been arranged has an empty one. |

| `--json` |  | emit response as JSON |
