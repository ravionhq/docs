### `ravion membership create`

Create Membership

```bash
ravion membership create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--email <string>` | yes | email |
| `--json` |  | emit response as JSON |
| `--role <roles>` |  | Deprecated: use roles. Writing it sets `roles` to this one role; it cannot be sent with `roles`. `OWNER` is accepted as `owner`. Reads return the member's role with the most access, or its first custom role. |
| `--roles <owner>` |  | The roles the member holds across the organization, each a system-managed role key (owner, `admin`, `member`, `viewer` or `billing`) or a custom role ID. A member holds at least one. Reads list system-managed roles from least to most access, then Billing, then custom roles by name. Setting `roles` replaces the whole set. Roles other than `owner` require policy administration to be enabled for the organization, and the caller can add or remove only roles whose permissions it already holds. |
