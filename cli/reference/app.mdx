Manage the apps `ravion deploy` deploys to App Clusters

| Flag | Required | Description |

### `ravion app list`

List the apps on an App Cluster

```bash
ravion app list [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--module-instance-id <minst_*>` | yes | App Cluster module instance (minst_*) whose apps to list. |
| `--cursor <string>` |  | cursor |
| `--json` |  | emit response as JSON |
| `--limit <int>` |  | limit |
| `--name <string>` |  | List only the app of this name and its branch apps. |
