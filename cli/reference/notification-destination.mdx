## `ravion notification-destination`

Manage notification destinations

**Aliases:** `notification-destinations`

### `ravion notification-destination create`

Create NotificationDestination

```bash
ravion notification-destination create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--config <kind>` | yes | The destination's address, discriminated by kind — a webhook URL, a Slack channel or user, or an email address. |
| `--enabled` | yes | Whether matched notification rules deliver to this destination. |
| `--kind <string>` | yes | Which channel this destination delivers to. Fixed at creation — create a new destination to change kind. Available values: SLACK_CHANNEL, SLACK_DM, EMAIL, WEBHOOK. |
| `--label <string>` | yes | User-facing label shown in destination lists. |
| `--connection-id <kind>` |  | Id of the active integration this destination delivers through. Required, and must reference an integration whose provider matches kind (SLACK for SLACK_CHANNEL and SLACK_DM, WEBHOOK for WEBHOOK). Absent for EMAIL, which carries no credential. |
| `--json` |  | emit response as JSON |
