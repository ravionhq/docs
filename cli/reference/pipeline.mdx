#### `ravion pipeline run get`

Read a single pipeline run.

This returns one snapshot. To follow a run to completion, use
`ravion pipeline run wait &lt;id&gt; --watch` instead of calling this command in a loop.

```bash
ravion pipeline run get <id> [flags]
```

**Examples:**

```bash
ravion pipeline run get prun_123
ravion pipeline run wait prun_123 --watch
```

**Flags:**

| Flag | Required | Description |

| `--json` |  | emit response as JSON |

#### `ravion pipeline run wait`

Wait for a pipeline run to finish, or to reach the status given by --until.

Use this instead of polling `ravion pipeline run get` in a loop. With --watch the command
prints run and step status changes as they happen, then exits when the run is done.

```bash
ravion pipeline run wait <id> [flags]
```

**Examples:**

```bash
ravion pipeline run wait prun_123 --watch
ravion pipeline run wait prun_123 --watch --timeout 30m
ravion pipeline run wait prun_123 --until PENDING_APPROVAL --watch
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--json` |  | emit response as JSON |
| `--timeout <duration>` |  | maximum time to wait; zero waits indefinitely |
| `--until <string>` |  | return when this status is reached, for example PENDING_APPROVAL |
| `--watch` |  | print run and step status changes while waiting |
