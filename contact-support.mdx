## Report a bug or send feedback

<Warning>
  For urgent or high-priority issues, email [support@ravion.com](mailto:support@ravion.com) in addition to filing a bug report. Filing a report through the CLI or API does not contact support. Include the same error details and resource IDs in your email.
</Warning>

The Ravion CLI files reports directly into our private triage for anything broken, confusing, or missing:

```bash
ravion bug "Deploy failed with 'module not found' after I renamed a module instance."
```

```bash
ravion feedback "Dry-run output is hard to read when many modules change at once."
```

See [Report bugs and feedback](/report-bugs-and-feedback) for what to include and how agents should use these commands.

## Email support

Email [support@ravion.com](mailto:support@ravion.com) for anything that needs a reply, including your account, billing, and urgent or high-priority issues.

CLI reports do not return a ticket ID, so email us if you need a status update on one.
