## Configure the deployment

The current Node deployment uses Vite and Nitro, producing a server entry at `.output/server/index.mjs`.

This example uses [Railpack](https://railpack.com) for the build. Use `build_source: dockerfile` instead when you need a custom Dockerfile.

Keep these scripts in `package.json`:

```json
{
  "scripts": {
    "build": "vite build && tsc --noEmit",
    "start": "node .output/server/index.mjs"
  }
}
```

The current TanStack Start hosting guide documents `vite build` with the Nitro Node output. The server listens on port `3000` by default. Set `PORT` and `HOST` through the service environment when your application needs explicit binding.

```yaml ravion.yaml
project:
  givenId: tanstack-start-app
  name: TanStack Start app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: tanstack-start-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: tanstack-start-production
      - givenId: web
        name: TanStack Start web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: tanstack-start-production-web
          build_source: railpack
          source_repo: my-org/my-tanstack-start-app
          railpack_build_cmd: npm run build
          railpack_start_cmd: npm start
          container_port: 3000
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

## Apply and connect your domain

```bash
ravion project create --given-id tanstack-start-app --name "TanStack Start app"
ravion project config apply tanstack-start-app --file ravion.yaml --dry-run
ravion project config apply tanstack-start-app --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to the Application Load Balancer.
