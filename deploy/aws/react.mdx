## Configure the deployment

Vite projects write to `dist`; Create React App projects write to `build`.

This example uses [Railpack](https://railpack.com) for the build. Use `build_source: dockerfile` instead when you need a custom Dockerfile.

This example deploys a Vite React app.

```yaml ravion.yaml
project:
  givenId: react-site
  name: React site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: React site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: react-site-production
          build_source: railpack
          source_repo: my-org/my-react-app
          railpack_build_cmd: npm run build
```

For Create React App, add `output_directory: build` to the module input. The default `spa` routing mode serves `index.html` for client-side routes.

## Apply and connect your domain

```bash
ravion project create --given-id react-site --name "React site"
ravion project config apply react-site --file ravion.yaml --dry-run
ravion project config apply react-site --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to CloudFront.
