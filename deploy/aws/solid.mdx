## Configure the deployment

The S3 bucket and CloudFront distribution are provisioned in your AWS account.

This example uses [Railpack](https://railpack.com) for the build. Use `build_source: dockerfile` instead when you need a custom Dockerfile.

```yaml ravion.yaml
project:
  givenId: solid-site
  name: Solid site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: Solid site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: solid-site-production
          build_source: railpack
          source_repo: my-org/my-solid-app
          railpack_build_cmd: npm run build
```

The Solid Vite starter uses `npm run build` and writes to `dist`. Use `VITE_*` variables for values embedded in browser code.

## Apply and connect your domain

```bash
ravion project create --given-id solid-site --name "Solid site"
ravion project config apply solid-site --file ravion.yaml --dry-run
ravion project config apply solid-site --file ravion.yaml
```

Point DNS at the CloudFront hostname with [custom domains](/guides/custom-domains).
