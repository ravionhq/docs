## Configure the deployment

Choose `adapter-static` for a prerendered site on S3 and CloudFront, or `adapter-node` for a Node server on ECS Fargate behind an Application Load Balancer.

This example uses [Railpack](https://railpack.com) for the build. Use `build_source: dockerfile` instead when you need a custom Dockerfile.

Install `@sveltejs/adapter-static`, prerender the routes you need, and keep the adapter output in `build`.

```yaml ravion.yaml
project:
  givenId: sveltekit-static
  name: SvelteKit static site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: SvelteKit static site
        type: rvn-aws-static
        version: 1.9.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: sveltekit-static-production
          routing: filesystem
          build_source: railpack
          source_repo: my-org/my-sveltekit-site
          output_directory: build
          railpack_build_cmd: npm run build
```

## Node adapter

Install `@sveltejs/adapter-node`. `npm run build` writes a standalone server to `build`, and `node build` starts it on port `3000`.

```yaml ravion.yaml
project:
  givenId: sveltekit-app
  name: SvelteKit app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.3.1
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: sveltekit-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 2.4.0
        input:
          network:
            moduleGivenIdRef: network
          name: sveltekit-production
      - givenId: web
        name: SvelteKit web service
        type: rvn-ecs-web
        version: 2.9.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: sveltekit-production-web
          build_source: railpack
          source_repo: my-org/my-sveltekit-app
          railpack_build_cmd: npm run build
          railpack_start_cmd: node build
          container_port: 3000
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

The Node adapter reads `PORT` and `HOST` environment variables. Bind to `0.0.0.0` in ECS.
