## Platform

### Breaking changes

- **Removed top-level pipeline rollback:** Remove the unsupported `rollback` key from pipeline configurations before applying them. Pipeline rollback is a planned future feature.

### Features

- **Templated infrastructure types:** Use templates that resolve to different infrastructure types when a pipeline step runs.

### Improvements

- Billing plan cards now make the whole card the change-plan action when a payment method is missing.
- Trial notices now reserve urgent styling for the final three days.
- Module reference fields now offer reference suggestions when values are entered manually.
- Key-value fields now edit existing pairs in place, use the available width, and accept pasted JSON pairs.
- Project breadcrumbs now link to the project from module pages without sending users back to the current page.
- Default Terraform pipelines now pass execution environment overrides to their plan and apply steps.
- Module status now reports `STACK_DESTROYED` after a successful stack destroy and excludes Terraform data sources from resource counts.

### Fixes

- Reapplying configuration with omitted immutable inputs now keeps their stored values.
- Environment Logs now identifies AWS access denials and guides customers to update account permissions.
- Applying project configuration now resolves system pipeline defaults for environments that do not yet exist.
- Listing a stack's current Terraform state now works when large state values would otherwise exhaust database sort memory.
- ECS deployments now preserve the service's existing tag propagation setting.
- Transient binary download failures now retry with backoff before reporting an error.
- EC2 deployments now use the repository's default branch when no source branch is supplied.
- Missing applied-module outputs now produce a specific validation error at the affected field.

## AWS account IAM policy 1.0.48 → 1.0.50

- **AMI deployment permissions:** The first AMI build in an account can create EC2 Image Builder's service-linked role.

Update your AWS account connection in [**Settings / AWS accounts**](https://app.ravion.com/org/settings/aws-accounts).

## Platform
### Features
- **Module output references:** Set any module input from another module's stack output with a `<< >>` template in the dashboard, the project config file, or a pipeline, including across environments and projects. See [output references](https://www.ravion.com/docs/modules/output-references).
- **AMI deployments:** The new [AMI](https://www.ravion.com/docs/module-definitions/catalog/rvn-aws-ami) module releases an AMI with every deploy. Each deploy builds the image with EC2 Image Builder, copies it to every region, publishes it when requested, and retires older images. Redeploys and rollbacks release earlier images again without rebuilding.
- **New project navigation:** A new project sidebar keeps environments and pipelines visible and easy to navigate. When viewing a module, a module sidebar lets you switch to another module.
### Improvements
- Deployment logs now show that they are waiting when a running step has not produced logs yet.
- The dashboard now uses a scaled desktop layout on phones so content fits the screen.
- Projects pages now open the only project directly when you enter an organization with one project.
- Route loading now shows page-specific skeletons instead of a blank dashboard shell.
- [`instance_size`](https://www.ravion.com/docs/pipelines/config-reference#ec2stepinfrastructure) arrays are now accepted for EC2 infrastructure configuration.
### Fixes
- Email verification now lets users request a fresh code when the original code expires or is rejected.
- Published module versions now load correctly when opening a module version pane.
- Failed resource loads now show an error with a retry option instead of an endless loading state.
- GitLab subgroup repository URLs now work in code-source lookups and no longer appear as unexpected server errors when unconnected.
- Authenticated requests for Terraform resources with encoded slashes now remain authenticated.
- EKS deployments now release abandoned targets and report blocked deployments instead of waiting indefinitely.
- Project configuration dry runs now fail clearly when a values input names no connected resource.
- Failed requests now retry only transient network, timeout, gateway, and rate-limit errors, while deterministic errors are not resent.
