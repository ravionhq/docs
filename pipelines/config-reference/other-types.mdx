## Other types

### PipelineConfigTarget

The pipeline a pipeline config file is for. It identifies the target and is
never stored on a pipeline version.

<ResponseField name="id" type="string">
  Pipeline ID, such as pipe_3HpMAgQNqx2TTUDEakfaELp3hi3
</ResponseField>

<ResponseField name="givenId" type="string">
  Pipeline given ID, used when the file has no id. A given ID is unique
  within its project, so project names the project too.
</ResponseField>

<ResponseField name="project" type="string">
  The pipeline's project, by ID or given ID; required with givenId
</ResponseField>

<ResponseField name="name" type="string">
  Pipeline name, for readers of the file
</ResponseField>
