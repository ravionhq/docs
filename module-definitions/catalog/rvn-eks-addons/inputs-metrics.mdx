### Metrics

<ResponseField name="metrics_enabled" type="boolean">
  **Metrics.** Collect workload and Kubernetes metrics and send them to the selected destinations. Disabling metrics removes the managed metrics collectors.

  - Default: `true`
</ResponseField>

<ResponseField name="metrics_providers" type="string_array">

  - Default: `["prometheus"]`
  - Allowed values: `amp` (Amazon Managed Prometheus), `prometheus` (Prometheus in your cluster), `mimir` (Grafana Mimir in your cluster (large clusters)), `cloudwatch` (Amazon CloudWatch (Container Insights)), `grafana_cloud` (Grafana Cloud Metrics), `datadog` (Datadog), `new_relic` (New Relic), `otlp` (Custom OTLP endpoint)
  - Shown when: `{"metrics_enabled":true}`
</ResponseField>

<ResponseField name="amp_workspace_id" type="string">

  - Shown when: `{"metrics_enabled":true,"metrics_providers":"amp"}`
</ResponseField>

<ResponseField name="amp_workspace_region" type="string">
  **Workspace region.** AWS Region containing the workspace. Leave blank to use the cluster Region. A different Region sends metrics across Regions.

  - Shown when: `{"metrics_enabled":true,"metrics_providers":"amp"}`
</ResponseField>

<ResponseField name="grafana_role_creation_enabled" type="boolean">

</ResponseField>

      - Shown when: `{"provider":{"not":"basic"}}`
    </ResponseField>
    <ResponseField name="allowed_domains" type="string_array">
      **Allowed domains.** Email domains whose accounts can sign in. For Google, your Google Workspace domains.

      - Shown when: `{"provider":{"not":"basic"}}`
    </ResponseField>
    <ResponseField name="allowed_organizations" type="string_array">
      **Allowed organizations.** GitHub organizations, Entra ID tenant IDs, or the provider's organizations whose members can sign in.

      - Shown when: `{"provider":["github","azuread","generic_oauth"]}`
    </ResponseField>
    <ResponseField name="allowed_groups" type="string_array">
      **Allowed groups.** Groups whose members can sign in. Google takes Workspace group emails, and needs the Cloud Identity groups scope under Scopes. Entra ID takes group object IDs.

      - Shown when: `{"provider":["google","gitlab","azuread","okta","generic_oauth"]}`
    </ResponseField>
    <ResponseField name="team_ids" type="string_array">
      **Allowed team IDs.** Numeric IDs of teams whose members can sign in.

      - Shown when: `{"provider":["github","generic_oauth"]}`
    </ResponseField>
    <ResponseField name="role_attribute_path" type="string">
      **Role mapping.** JMESPath over user info that returns Admin, Editor or Viewer, checked at every sign-in. Blank uses the default role.

      - Shown when: `{"provider":{"not":["azuread","basic"]}}`
    </ResponseField>
    <ResponseField name="settings" type="object">
      **Other Grafana settings.** Any other key of Grafana's [auth.\<provider>] section, as JSON, passed through verbatim, such as \{"auto_login": "true"\}. The client secret goes in the ARN above, never here.

      - Default: `{}`
      - Shown when: `{"provider":{"not":"basic"}}`
    </ResponseField>
  </Expandable>
</ResponseField>
