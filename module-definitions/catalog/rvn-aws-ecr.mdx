## Readme

Creates a private Amazon ECR repository for container images with scan on push, image cleanup, optional KMS encryption, and cross-account access.

### Overview

Use this module to keep container images in a private Amazon ECR repository for application services and CI pipelines. Images are scanned on push by default, and the repository can grant selected AWS principals pull or push access.

### Use cases

| Scenario | Benefit |
| --- | --- |
| Store application images | Keep images in a private repository for ECS, EKS, or other container workloads. |
| Share images across accounts | Grant selected IAM principals pull or push access to the repository. |
| Retain recent builds | Expire old images with the built-in lifecycle policy. |

### Image cleanup

Cleanup is enabled by default. The policy expires untagged images after 14 days and keeps the newest 100 images (tagged or untagged), matching the policy used by ECS and EKS service repositories. Change the two counts to suit your rollback needs.

Raw JSON lifecycle policies are available only through Advanced Terraform variables as `lifecycle_policy`; when set, that policy takes precedence over the built-in rules.

### Repository access

Pull principal ARNs grant image pull access, while push principal ARNs grant pull and push access. Both lists are empty by default. For principals in the same account, IAM policies can grant access without adding a repository policy.

Raw JSON repository policies are available only through Advanced Terraform variables as `repository_policy`; when set, that policy takes precedence over the principal lists.

### Encryption

Repositories use AES-256 encryption with an AWS-owned key by default. Choose AWS KMS to use a customer-managed key; leaving KMS key ARN empty uses the AWS-managed `aws/ecr` key. Encryption type and KMS key ARN are immutable because changing either replaces the repository.

### Design decisions

The form defaults to mutable tags, scan on push, and image cleanup. The cleanup defaults preserve recent images while placing a time limit on untagged images.

Encryption type and KMS key ARN cannot be changed after creation because ECR replaces the repository when these settings change. Force deletion is off by default.
